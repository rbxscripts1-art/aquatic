# AQUATIC: сайт с аккаунтами и админ-панелью

Нужен только Node.js 18 или новее. Ничего устанавливать через npm не нужно.

## Запуск

```
node server.js
```

Сайт откроется на http://localhost:3000

## Админ SHADOW

Аккаунт SHADOW уже создан. Временный пароль лежит в `config.json`, поле `adminPassword`.

Чтобы поставить свой пароль:
1. Откройте `config.json` и впишите свой пароль в `adminPassword`.
2. Перезапустите сервер. Пароль обновится сам, а старые входы SHADOW завершатся.

После этого лучше убрать пароль из `config.json` и хранить его у себя: сервер хранит в базе только хеш.

## Что умеет админ-панель

Кнопка «Админ-панель» появляется в шапке после входа админа.

- **Игроки:** список всех аккаунтов, поиск, выдача привилегии через выпадающий список.
- **Привилегии:** создание своей привилегии с названием и цветом, смена цвета, удаление.
- Встроенные привилегии: «Игрок» и «Админ». Свои создаются без ограничений (до 30).
- Роль «Админ» выдаёт и снимает только владелец (SHADOW). Остальные админы управляют игроками и своими привилегиями.
- Привилегию владельца изменить нельзя.

## Настройки (`config.json`)

- `port`, `host`: порт и адрес сервера (можно задать через переменные PORT и HOST).
- `adminNick`: ник владельца, по умолчанию SHADOW.
- `adminPassword`: пароль владельца.

## Что подставить

- Ссылка на скачивание клиента: в `public/index.html` кнопки «Скачать» ведут на блок «Как начать».
- Бот поддержки уже настроен: https://t.me/Aquatichelp_bot

## Важно при размещении в интернете

- Пароли передаются по сети, поэтому ставьте сайт за HTTPS (например, через nginx или Caddy).
- Все данные лежат в `data/data.json`. Делайте его копию и не публикуйте папку `data`.
